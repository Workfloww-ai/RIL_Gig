Color Palette

Primary Red: #E31B23 (used for action buttons like "ENQUIRE NOW", primary brand accents, and main headline emphasis)

Dark Charcoal / Almost Black: #1A1A1A or #222222 (used for main headline text, major titles, and key numbers)

Muted Grey: #666666 (used for body text, subtitles, and secondary descriptions)

Soft Off-White / Light Grey: #F7F8F9 (used for subtle container backgrounds and quote cards)

Pure White: #FFFFFF (used as the primary page background and card fill)

Forest Green: #10472B (used for specific callout blocks and background containers further down the page)

Typography & Styling

Headings: Bold, clean sans-serif typeface with tight letter spacing for a modern, high-impact aesthetic.

Body Text: Light-to-medium weight sans-serif font for readability across descriptions and bullet points.

Buttons: Solid rounded-rectangle buttons with high-contrast text (white text on vibrant red background).

Layout Structure: Clean, modern grid design with wide margins, rounded container cards, and high contrast for scannability.
